# 术语速查

| 术语 | 在这里的含义 |
| --- | --- |
| 核心 | 实际处理规则、协议与连接的引擎 |
| 入站 listener | 服务端接受代理请求的入口 |
| 出站 outbound | 请求下一跳的连接方式 |
| SNI | TLS 客户端指明的服务名称，不是密码 |
| ALPN | TLS 中协商应用协议，例如 h2/h3 |
| UUID | 某些协议使用的身份标识；不要公开真实值 |
| RTT | 一次往返延迟 |
| TTFB | 请求开始至响应首字节时间 |
| goodput | 成功传输的有效负载速率 |
| Mbps / MiB | 十进制兆比特每秒 / 1024² 字节 |
| BBR | 基于带宽与 RTT 模型的拥塞控制家族 |
| MTU / PMTU | 链路/整条路径允许的包大小限制 |
| NAT / conntrack | 地址转换 / 内核连接追踪 |
| DNS-01 | 通过 TXT 记录证明域名控制权的 ACME 挑战 |
| staging | 用于演练的证书环境，不受普通客户端信任 |
| fallback | 按优先顺序选择可用节点 |
| url-test | 根据指定 URL 的测量延迟选择节点 |
| SLI / SLO | 服务测量指标 / 为该指标设定的目标 |
| 错误预算 | 测量窗口中允许不满足目标的部分 |
| RTO / RPO | 目标恢复时间 / 可接受的数据丢失时间窗口 |
| 控制面 / 数据面 | 管理身份与配置 / 实际承载用户请求 |
| Lish / 恢复控制台 | 云平台提供的带外管理通路，用于 SSH 失联后恢复 |
