# 01 · 一次请求经过哪些系统

**目标：** 能画出数据流，并说明每个部件失效影响什么。**前置：** 会导入客户端配置即可。

## 从浏览器到目标网站

```text
浏览器 / 应用
  ↓ 本机 HTTP/SOCKS 代理，或客户端 TUN 接管
客户端核心：解析目标 → 匹配规则 → 选择节点
  ↓ 加密代理连接，经过家庭网络 / 运营商 / 跨境路径
云防火墙 → Docker 发布端口 → 服务端核心监听器
  ↓ 验证身份 → 检查目标规则 → 创建对外连接
目标网站（HTTPS 加密仍由应用与网站负责）
```

Mihomo 是连接处理引擎。Clash Verge Rev、Clash Mi 是管理引擎与系统接管的应用；“应用版本”和“内核版本”是两个坐标。协议描述双方怎样交换数据；VPS 提供进程、网络和出口。域名只是地址名称，不能自动带来证书、认证或加速。

默认的本机代理端口只监听回环地址。没有开启 TUN 或系统代理的应用可能绕过它，所以“客户端显示已连接”不等于所有设备流量都已接管。

## 三条相互独立的通路

| 通路 | 内容 | 故障影响 |
| --- | --- | --- |
| 数据通路 | 用户请求与返回数据 | 正在使用的连接受影响 |
| 配置通路 | HTTPS 订阅文件 | 更新配置失败；已缓存配置可能继续使用 |
| 管理通路 | SSH、云控制台、Lish | 维护受影响；不代表数据通路一定断开 |

订阅下载服务使用另一个受限容器；服务器管理 API 不对外开放。文档站点与这三条通路均没有控制关系。不要把学习网站部署到生产节点后误当成管理平台。

## 读代码

查看 `jp/config.py` 的 `client_config` 与 `server_config`：客户端 `MATCH,node` 把测试请求固定到单个入口；服务端先拒绝私网目标，再允许出口转发。这是两台核心的不同角色，不是规则互相矛盾。

## 练习与检查点

在纸上标出证书在哪里验证、Cloudflare DNS API 在哪里使用。答案：普通 TLS 入口证书由客户端验证；DNS API 供 ACME 工具修改挑战记录，不参与每一次代理连接。

若订阅域名暂时解析失败，已有 IP 地址节点是否一定断流？不一定；取决于缓存配置、节点地址及解析依赖。若 VPS 整体宕机，同一 VPS 的九个协议是否构成九份高可用？不构成。
