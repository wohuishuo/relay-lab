# 从一条连接开始，理解整个代理系统

RelayLab 是个人节点的工程实验室。这套课程带你沿着一次请求，理解协议、DNS、证书、性能与运维。目标是能解释现象、设计验证、识别证据的边界，而不只是复制参数。

> 阅读约 3 小时；实验另计。先读 01–03，再按任务选择后续章节。所有命令默认在源码根目录执行；Windows 使用 `python`，Ubuntu 使用 `python3`。

## 每一页怎样使用

先读“目标”和“前置”，再跟随概念、源码与实验。最后完成检查点；不会答时返回对应数据流，不必背诵配置字段。

课程中的三类标签具有不同含义：**本地已验证**来自仓库报告；**机制解释**来自固定版本源码或官方规范；**待验证假设**没有被当成生产结论。真实客户端应用的版本兼容性，需要设备端重新验收。

本轮研究没有连接或修改现有服务器，也没有修改正在使用的订阅。站点是文档阅读界面，不是远程管理后台。

## 毕业练习

在全新的本地状态目录完成 SS 正负认证测试；解释为什么错误密码与 SYN 超时属于不同层；用下载限速实验复现不对称；给出一个不会影响现有用户的改进试验。提交脱敏报告，注明没做的测试。
